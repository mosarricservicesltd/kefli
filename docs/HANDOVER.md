# Handover: picking Kefli up on another computer

Written on 6 October 2026, when the work moved off the laptop it started on. Everything needed is in this repository; this page says where things are, what is in flight, and how to set a new machine up. `CLAUDE.md` stays the project's standing brief and Claude Code reads it automatically; this page adds the state of play.

  - **Pending parses** (sync phase 7): a share made offline is saved and waits on the phone. A page that can't be read is sent without text. Shared X posts (5.4) are checked through X's embed service, with `t.co` followed five hops at most: the first link that leaves X is saved, and a post with no article saves nothing. Offline, or with X not answering, the post waits as a pending save and is checked again (retried from 30 s, doubling to an hour, while X fails), then re-keyed to its article (FD 80).

## Known issues

- **A share can hang its card on a cold start (seen twice on 7 October 2026, not reproduced since).** When a share starts Kefli's process while an old MainActivity is still listed in the background, the "main" surface starts alongside the "share" surface, and the share card stops drawing after its save. The save itself is recorded and its rows are released at the next start, so nothing is lost; the card stays grey until Back. To look at in week 2 with the real share sheet.

## Setting up a new machine

Install Git, Node 24, Google Chrome, and for the phone build JDK 17 and the Android SDK (Android Studio installs it; set `ANDROID_HOME`). Then:

```bash
git clone git@github.com:richardminton-glitch/Kefli.git
```

Clone with your own GitHub SSH key as above, or over HTTPS (`https://github.com/richardminton-glitch/Kefli.git`). The repository took the name Kefli on 9 October 2026 (rename plan R7); GitHub redirects its old address, but point an old clone at the new one with `git remote set-url origin git@github.com:richardminton-glitch/Kefli.git`. Some networks block SSH's port 22: if `git push` times out, add this to `~/.ssh/config` and clone from `git@github.com:` as usual.

```
Host github.com
  HostName ssh.github.com
  Port 443
```

| Rebuild the brand files | install `@resvg/resvg-js@2` somewhere outside the repo, then `NODE_PATH=<that folder>/node_modules node shared/brand/build-icons.cjs` |
| Rebuild the parser bundle | `node shared/vendor/build-parser-bundle.mjs` (writes the APK asset and its sha256 into `apps/mobile/modules/kefli-parser`; `--check` for CI). After a runner change, `npx tsx shared/fixtures/build-pages.ts` remakes the twenty fixture pages' expected results in desktop Chrome (`--fetch` downloads the real pages again) |
| Build the app for the phone | From the root, `npm install`. In `apps/mobile`: `npm run make-ticks` (the test track, kept out of git), then `KEFLI_VARIANT=local npx expo prebuild --platform android` for the local stack (cleartext to localhost only), or `KEFLI_DEFAULTS_URL=https://…/defaults.json` for a build against a real operator; then in `apps/mobile/android`, `./gradlew assembleRelease -PreactNativeArchitectures=arm64-v8a` with the same variable set, since Gradle reads the app config again. Install with `adb install -r app/build/outputs/apk/release/app-release.apk`. After changing JavaScript outside `apps/mobile`, delete `app/build/generated/assets/react` first, or Gradle keeps the old bundle |

Commits to `main` go through the code-gate CRAP check (CLAUDE.md, Rules). On this laptop it ran as a git pre-commit hook from Claude's code-gate skill; a new machine needs the hook installed again before the first commit.

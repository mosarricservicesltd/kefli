# apps/web: the Kefli website

A static site, built with Vite, for the apex domain (kefli.app):

| Page | What it's for |
|---|---|
| `/` | The landing page: the summit above the fog, how it works, why the library outlives us, the name, and the downloads. Built from the chosen prototype, `docs/design/web/option-a-above-the-fog.html`. |
| `/privacy/` | The privacy note: mobile spec 7.3's lines, contract section 1's account of what servers see, and the backend's log and backup policy. |
| `/extension/` | The one-page install guide for the extension in developer mode (extension spec section 11), with pairing and permissions. |
| `/extension-privacy/` | The extension's privacy note, the address its store listings give (extension spec 12), brought up to date with contract v1.5. |
| `/delete-account/` | The deletion page Google Play requires (mobile spec 13.1), following the app's Delete my data route (flow decision 86, contract 4.7). |

## Commands

```
npm run dev -w apps/web        # local server with hot reload
npm run build -w apps/web      # static site in apps/web/dist
npm run preview -w apps/web    # serve dist locally
npm test -- --selectProjects web   # the scene geometry, from the repository root
npm run typecheck -w apps/web
npm run fonts -w apps/web      # re-cut the web fonts (only when the sources or the subset change)
npm run tokens                 # from the root: regenerates src/styles/tokens.css with everything else
```

## Links and downloads

Every download, store and contact link comes from `.env` (override locally in `.env.local`). A link still set to `#` builds as a plain element marked Soon, never a button that goes nowhere, so the site can ship before Zapstore, the APK, the stores or the source repository are public. Set the real addresses and rebuild.

## What it's made of

- **Tokens.** `src/styles/tokens.css` is generated by `shared/tokens/build-css.mjs`, the same values as the prototypes. The site is a deliberate single light look; the footer is the one graphite surface.
- **Fonts.** Self-hosted, so a visit asks no third party for anything: `scripts/fonts.mjs` cuts Latin subsets, axes kept, from the pinned OFL sources in `shared/fonts/src` into `public/fonts`. (The prototypes still load Google Fonts; `tokens.json`'s note that the website does too is the one place that now differs.)
- **Brand.** Favicons, app icons, the social card, the web manifest and the two marks are copied from `shared/brand/out` by `scripts/brand.mjs` before every dev and build run, and git-ignored here.
- **Media.** The summit and dusk plates, their cloud loops and the cut-out ridge are in `public/media`, generated with Higgsfield; how each was made is in `public/media/SOURCES.md`. The ridge's crest profile in `src/scene/geometry.ts` is measured from the cut and must be regenerated with it.
- **Scene code.** `src/scene/geometry.ts` holds every number the scene uses, free of the DOM and tested in `test/`. `summit.ts` and `dusk.ts` apply it; both pause when off-screen or in a hidden tab, and under reduced motion show the photographs alone, with no loops and no scroll effects.

## Serving it

Caddy on the operator's host serves `dist/` on the apex, beside `relay.`, `api.` and `blossom.` (backend spec section 5). Keep the apex's rewrite of `/.well-known/nostr.json` to `keflid` (backend spec, NIP-05) ahead of the file server, and give `/media/` and `/fonts/` and `/assets/` long cache lifetimes: the assets are content-hashed, and the media and fonts change only with their file names.

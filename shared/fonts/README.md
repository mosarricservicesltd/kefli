# Fonts

The app's static font cuts (mobile spec 6.3), made from the variable sources in `src/`.

| File | What it is |
|---|---|
| `src/` | The variable fonts from Google Fonts (`github.com/google/fonts`, `ofl/archivo`, `ofl/literata`, `ofl/martianmono`, fetched 6 October 2026 at commit `7085eb89a950`) with their licences. All three are under the SIL Open Font License 1.1, which travels with them, and none reserves a font name. |
| `cuts.json` | Generated by `shared/tokens/build-ts.mjs` from `tokens.json`: each family name and the axes it pins. |
| `cut-fonts.py` | Cuts each family with fontTools 4.60 (`varLib.instancer`), renames it, and fixes its timestamps, so a cut is byte-identical on every run. `--check` fails when `out/` is stale. |
| `out/` | The fifteen cuts the app bundles, one expo-font family each. |
